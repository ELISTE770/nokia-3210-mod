# nokia_pac.py

כלי לפירוק ובנייה של קובצי PAC של Spreadtrum/Unisoc, ולעריכת תפריט המכשיר
בתוך קובץ ה-nvitem של נוקיה 3210 4G.

לא נדרשות ספריות חיצוניות — Python 3.9 ומעלה בלבד.

## פקודות

```bash
python nokia_pac.py info 3210.pac
python nokia_pac.py verify 3210.pac
python nokia_pac.py extract 3210.pac out/
python nokia_pac.py menu-show nvitem.bin
python nokia_pac.py menu-edit nvitem.bin nvitem_new.bin --remove 04,18,19,1F
python nokia_pac.py build 3210.pac 3210_new.pac --replace NV=nvitem_new.bin
python nokia_pac.py nv-records nvitem.bin --id 0x2A8
```

`--replace` מקבל גם מזהה מחיצה (`NV`, `MMIRes`) וגם שם קובץ (`apn.bin`),
ואפשר לחזור עליו כמה פעמים.

## מה נמדד ולא נלקח מתיעוד

**מכולת PAC**
- כותרת 2124 בתים, חתימה `0xFFFAFFFA` ב-2116
- `crc1` (u16 ב-2120) = CRC-16/ARC על בתים `[0, 2120)`
- `crc2` (u16 ב-2122) = CRC-16/ARC על בתים `[2124, סוף)`
- טבלת מחיצות מיד אחרי הכותרת, 2580 בתים לרשומה
- הנתונים ארוזים ברצף אחרי הטבלה, בלי ריפוד

**nvitem**
- רשומות בפורמט `<id:u16><len:u16><data>`, כל אחת מיושרת ל-4 בתים,
  הראשונה ב-offset 4
- רשומה `0x02A8` (680) מחזיקה את התפריט, 408 בתים:

```
dword 0        מונה לתפריט 3x3
dword 1        מונה לתפריט 1x1
dword 2..51    פריטי 3x3   (50 מקומות, 26 בשימוש בקושחה המקורית)
dword 52..101  פריטי 1x1   (50 מקומות, 26 בשימוש)
```

מכיוון שיש 50 מקומות ורק 26 בשימוש, הסרת פריט לא משנה את אורך הרשומה
ולא את גודל הקובץ.

## אזהרה על הקודים

מיפוי הקודים לשמות (`0x04` = אינטרנט וכולי) מגיע מהקהילה במתמחים טופ,
**ולא אומת מול מכשיר.** עשרה קודים נותרו לא ממופים ומוצגים כ-`?`.
לפני הסתמכות על קוד מסוים, הרץ `menu-show` והצלב מול התפריט שעל המסך.

## בטיחות

- הכלי מסרב לדרוס קובץ קיים
- `build` מאמת אחרי הכתיבה: שני ה-CRC, שדה הגודל, ושכל מחיצה שלא נגעו
  בה חוזרת זהה בייט-בבייט
- `menu-edit` מסרב לתפריט ריק או לרשימה שחורגת מ-50 פריטים
