# Gemini for Nokia 3210 4G — צד השרת (פרוקסי חלופי / Legacy Fallback)

> [!NOTE]
> זהו מימוש הפרוקסי הישן והחלופי (PHP cPanel Proxy).
> **תוכנית האב המרכזית והרשמית** של הפרויקט היא לאונצ'ר חכם מובנה מבוסס C ו-MicroPython הרץ ישירות מכרטיס הזיכרון (In-OS Hooking), כמתועד ב-[`MASTER_PLAN.md`](../MASTER_PLAN.md).

דף PHP יחיד שמריץ שיחה עם Gemini בדפדפן של הנוקיה (משמש כגיבוי במידה ולא מריצים את הלאונצ'ר הישיר).

## התקנה ב-cPanel

1. העלה את `index.php` ל-`public_html` (או לתת-תיקייה).
2. צור קובץ מפתח **מחוץ ל-`public_html`**, למשל `/home/USERNAME/gemini_key.txt`,
   ובתוכו רק מפתח ה-API של Gemini, בלי רווחים ובלי שורות נוספות.
3. ב-`index.php` עדכן:
   - `KEY_FILE` — הנתיב המלא לקובץ מהשלב הקודם.
   - `ACCESS_CODE` — קוד גישה משלך. אל תשאיר `CHANGE-ME`.
4. ודא ש-`curl` מופעל ב-PHP (ברוב חבילות ה-cPanel הוא דלוק כברירת מחדל).

## למה הדף נראה כמו 2004

כל בחירה כאן נגזרת ממה שנמדד בקושחה של המכשיר:

| אילוץ במכשיר | מה זה מחייב בדף |
|---|---|
| אין מנוע JavaScript שימושי | כל תור הוא POST של טופס. אין AJAX. |
| מנוע XHTML/WML עם libcss | תגיות בלוק פשוטות, CSS מינימלי. |
| מסך 240x320 | עמודה אחת צרה, שורות קצרות. |
| זיכרון מוגבל | התמלול לא נשלח למכשיר. |
| mbedTLS 2.6, ערכות RSA בלבד | ראה סעיף TLS למטה. |

## TLS — חשוב

בטלפון יש **תעודת שורש אחת בלבד: GoDaddy Root CA G2**, ואין תמיכה ב-ECDHE.
המשמעות:

- תעודת Let's Encrypt שמנפיק cPanel **לא תעבוד** (היא משתרשרת ל-ISRG Root X1).
- הפתרונות: לשרת את הדף ב-**HTTP רגיל**, או להתקין תעודה מ-**GoDaddy**.
- אם בוחרים HTTPS, השרת חייב להציע ערכה ישנה כגון
  `TLS_RSA_WITH_AES_128_CBC_SHA` או `TLS_RSA_WITH_AES_128_GCM_SHA256`.
  באחסון שיתופי אין בדרך כלל שליטה על זה — ולכן HTTP הוא ברירת המחדל המעשית.

## ניהול השיחה

אין אחסון בצד השרת. מזהה השיחה של Gemini (`previous_interaction_id`) נשמר
בשדה נסתר בטופס, והטלפון רק מעביר אותו הלאה. הקישור "שיחה חדשה" מאפס אותו.

## מה אומת מול ה-API החי

שלושה דברים שהתגלו רק בקריאה אמיתית, ולא היו נתפסים בבדיקה מקומית:

1. **`max_output_tokens` חייב לשבת בתוך `generation_config`.** כפרמטר עליון
   ה-API מחזיר `Unknown parameter`.
2. **השדה `output_text` לא מוחזר ב-REST.** ה-SDK חושף אותו, הנקודה הגולמית לא.
   הקוד קורא את `steps[]` ומדלג על צעדי `thought`.
3. **`max_output_tokens` סופר גם טוקני חשיבה.** בתקציב 400 עם
   `thinking_level: low` נמדדו 383 טוקנים לחשיבה ו-13 לתשובה, והיא חזרה
   קטועה עם `status: incomplete`.

לכן: תקציב 800, `thinking_level: minimal`, וזיהוי של `status: incomplete`
שמסמן תשובה קטועה ב-`[…]` במקום להציג אותה כשלמה.

**עלות:** עם `minimal` נמדדו כ-111 טוקנים לחילופי שאלה-תשובה קצרים,
לעומת 490 עד 610 עם `low`. זמן תגובה ממוצע כ-3.5 שניות.
