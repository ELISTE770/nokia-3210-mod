3. FDL1 & FDL2 (Flash Download Loaders)
--------------------------------------------------------------------------------
- FDL1 Base: 0x00006200 (Code: 0x00006400)
  * USB UART BROM communication handler
  * Baud rate negotiation and DDR memory sizing
- FDL2 Base: 0x80100000 (Code: 0x80100200)
  * Implements Unisoc BSL (Bootloader Security Link) protocol
  * Flash erase, block write, and NVItem programming commands

--------------------------------------------------------------------------------
4. EXEC_KERNEL_IMAGE (MOCOR RTOS Core) - Base: 0x80000000
--------------------------------------------------------------------------------
Key Subsystems:
- 0x80000000: Kernel Vector Table
- 0x80a061f4: kernel_entry_point
- RTOS Thread Scheduler (Preemptive priority-based multi-threading)
- Memory Pool Allocator: SCI_ALLOC / SCI_FREE
- Inter-Process Communication (IPC): SCI_SendEvent / SCI_GetEvent
- Cellular Baseband Interface: IPC shared memory with LTE/GSM DSPs
- File System: SFS (Spreadtrum File System) & FAT32 SDIO Driver (sdcard_read/write)

--------------------------------------------------------------------------------
5. EXEC_USER_IMAGE (Applications & UI) - Base: 0x80000000
--------------------------------------------------------------------------------
Key Subsystems:
- MMI Window Manager: MMI_CreateWindow / MMI_DestroyWindow
- Keypad Event Dispatcher: MMI_HandleKeyMsg
- NVItem Access Subsystem: NVITEM_Read / NVITEM_Write (Reads 0x02A8)
- Embedded Network Stack: Sockets, DNS, TCP/IP, and mbedTLS 2.6.0
